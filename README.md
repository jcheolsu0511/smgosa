# 에셈고사

2025학년도 에세머능력시험 성향 영역을 웹으로 옮긴 자가 검정.
실제 시험처럼 푸는 동안에는 채점하지 않는다. 다 풀면 답안지(OMR) 판독을 거쳐
등급과 오답 노트가 나온다.

```
표지 → 문제지 → 답안지 판독 → 성적표
```

## 여는 법

`index.html`을 더블클릭하면 된다. 빌드도 서버도 필요 없다.

누군가에게 보여 주려면 폴더째 정적 호스팅(GitHub Pages, Netlify, Vercel 등)에
올리면 그대로 돌아간다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 껍데기. 폰트와 스크립트만 불러온다 |
| `style.css` | 디자인 토큰 + 수능 문제지 조판 |
| `app.js` | 화면 전환, 출제, 채점, 저장 전부 |
| `questions-exam.js` | 2025 성향 영역(짝수형) 문항 26개 |
| `questions-safety.js` | 안전 지식 문항 84개 (현재는 안 불러온다) |
| `images/` | 그림 문항(18·23·31번) 삽화 |

스크립트는 ES 모듈이 아니다. `file://`로 열어도 돌아가게 하려고 일부러 평범한
`<script>`로 두었다.

## 출제 규칙

- 난이도 구분 없이 **26문항 전체**가 매번 나온다. 순서와 보기 순서만 섞인다
  (데이터의 `answer` 인덱스는 고정)
- 배점은 원본 정답지를 그대로 쓴다. `hard: true`가 3점, 나머지가 2점이라
  **만점 59점** (2점 19문항 + 3점 7문항)
- 등급은 백분율로 매긴다 — 96↑ 1등급, 90↑ 2, 83↑ 3, 75↑ 4, 66↑ 5, 56↑ 6,
  45↑ 7, 33↑ 8, 나머지 9등급
- 오답만 다시 풀기는 기록에 반영되지 않는다

주소 뒤에 `?n=107`을 붙이면 전 문항이 출제된다. 문항을 확인할 때 쓴다.

## 표지

홈 화면은 원본 문제지 표지를 그대로 옮긴 것이다. 성명·수험 번호 칸은 실제로
입력되고(성명은 기억되고 수험 번호는 8자리로 자동 생성된다), 필적 확인란에
`나를 강아지처럼 길들여줘`를 적어야 시작 버튼이 열린다. 공백은 무시하고 비교한다.

## 푸는 동안에는 알려주지 않는다

문제지 화면에서는 정답도 해설도 나오지 않는다. 고른 답만 채운 원문자로 표시되고,
진행 눈금도 맞았는지가 아니라 답했는지만 보여 준다. 답은 언제든 바꿀 수 있고
`이전 문항`으로 되돌아갈 수도 있다.

대신 성적표에서 한 번에 본다. 틀린 문항은 바로 펼쳐지고, 맞힌 문항 해설은
`맞힌 문항 해설도 보기`로 펼친다. 그러지 않으면 맞힌 문항의 해설을 영영 못 본다.

## 답안지(OMR)

채점 결과로 바로 넘어가지 않고 답안지를 먼저 보여 준다. 표시한 답이 그대로 칠해져
있고, 빛줄기가 한 번 훑고 지나가면(2.2초) `채점 결과 보기`가 열린다.
`prefers-reduced-motion`이면 기다리지 않고 바로 열린다.
성적표의 `답안지 보기`로 언제든 다시 볼 수 있다.

## 성적표 공유와 기록

- **성적표 이미지 저장** — canvas로 1000×1000 성적표를 그려 PNG로 내려받는다.
  트위터에 올리기 좋은 정사각이다. 그리기 전에 `document.fonts.load()`로
  쓸 자간·굵기를 명시해 로드시킨다. 이걸 빼면 명조가 적용되지 않는다
- **결과 복사** — 텍스트로 클립보드에 넣는다. `file://`에서는 클립보드 API가
  막히므로 textarea + `execCommand` 로 떨어진다
- **내 응시 기록** — 최근 20회를 저장하고 표지에 최고 기록과 최근 5회를 보여 준다

전부 이 브라우저 안에서만 돈다. 공개 랭킹을 붙이려면 서버가 필요하고,
채점이 클라이언트에서 도는 이상 점수 조작을 막을 수 없다는 점도 같이 고려할 것.

## 문항 추가

`questions-exam.js` 또는 `questions-safety.js`의 배열에 객체를 하나 더 넣으면 된다.

```js
{
  id: "고유 문자열",
  src: "출처 표기",            // 해설 아래에 표시된다
  subject: 0,                  // app.js의 SUBJECTS 인덱스 (0~5)
  hard: true,                  // 선택. 3점 후보로 먼저 뽑힌다
  passage: "지문",             // 선택. 문항 위 상자
  box: "〈보기〉 내용",          // 선택. 질문과 보기 사이 상자
  image: "images/q18.jpg",     // 선택. 보기 위 삽화
  imageNote: "출처 표기",       // 선택. 삽화 아래 캡션
  q: "질문",
  options: ["...", "..."],     // 4개 또는 5개
  answer: 0,                   // options 인덱스
  alsoCorrect: [1],            // 선택. 복수 정답
  explain: "해설",
}
```

작성 규칙:

- 오답 보기는 실제로 도는 잘못된 통념으로 만든다
- 해설은 2~4문장, 정답 반복이 아니라 새 정보를 하나는 담는다
- 응급 상황 문항의 해설은 "즉시 중단 / 진료"로 닫는다
- **해설에서 보기를 번호로 지칭하지 않는다.** 출제할 때마다 보기 순서를 섞으므로
  번호가 달라진다. 내용으로 지칭할 것

## 원본에서 뺀 문항

2025 성향 영역(짝수형) 45문항 중 26문항을 옮겼다.

- **1~17번** — 듣기 문제
- **34번** — 외부 애니메이션 캡처라 저작권 문제가 있다
- **26번** — 보기가 전부 유아 연령대라 뺐다

그림 문항 18 · 23 · 31번은 스캔본에서 삽화 영역만 잘라 `images/`에 넣었다.
문제지에 적힌 출처 표기(`@byo1004111`)가 그림 안에 박혀 있어 자르지 않고
통째로 썼고, 캡션으로 한 번 더 표기한다.

옮긴 23문항은 질문·보기 모두 원문 그대로다. 정답과 배점은 정답지 짝수형 표를
따랐고, 39번은 원본대로 복수 정답(③, ④)이다. 해설만 새로 썼다.

## 디자인

- 무채색 모노톤. 색으로 구분하지 않고 명도·채움·기호로 구분한다
  - 정답: 채운 원문자(❶) + 연회색 밴드 + `정답` 라벨
  - 오답: `✕ 내 답` 라벨 + 취소선 + 옅은 회색
  - 등급 도장: 4등급까지는 채우고 5등급부터는 비운다
- 색을 되살리려면 `style.css` 맨 위 `--correct` / `--wrong` 두 줄만 바꾸면 된다
- 라운드 2px, 애니메이션은 정답 판정과 해설 패널 열림에만,
  `prefers-reduced-motion` 존중
- 380 / 768 / 1280px에서 확인했다. 가로 스크롤 없음

### 폰트

명조는 Google Fonts의 Gowun Batang, 본문은 jsDelivr의 Pretendard를 쓴다.
외부 요청을 없애려면 `index.html`의 `<link>` 두 줄을 지우고 woff2를 받아
`@font-face`로 바꾸면 된다. 지워도 기본 글꼴로 정상 동작한다.
